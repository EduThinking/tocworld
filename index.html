☁️
구름 갈등구름 · Conflict Cloud
갈등 해결

서로 원하는 게 달라 부딪힐 때, 둘 다 진짜로 원하는 공통 목표를 찾아 해결책을 만드는 도구예요.

어떻게 쓰나요?

  1. A (공통 목표) — 우리가 함께 원하는 건 무엇인가요?
  2. B (욕구) — A를 이루려면 꼭 있어야 할 것 (한쪽 입장)
  3. C (욕구) — A를 이루려면 꼭 있어야 할 것 (다른 입장)
  4. D (원함) — B를 위해 구체적으로 원하는 것
  5. D' (원함) — C를 위해 구체적으로 원하는 것
  6. D와 D'가 왜 충돌하는지 살펴봐요
  7. 숨겨진 가정을 찾아, 그걸 깨는 해결책을 만들어요
🌿
가지 인과가지 · Branch
인과 분석

"이것이 있으면 → 저것이 생긴다"는 인과 관계를 화살표로 연결해, 문제의 흐름과 원인을 파악하는 도구예요.

어떻게 쓰나요?

  1. 시작 원인(A)을 적어요
  2. "A가 있으면 → B가 된다" 화살표로 연결해요
  3. B도 원인이 되어 → C로 이어지는 식으로 계속 연결해요
  4. 각 화살표마다 "왜?"를 물어 논리가 맞는지 확인해요
  5. 나무처럼 퍼지는 전체 흐름을 보면서 핵심 원인을 찾아요
🌳
야심찬 목표나무 Ambitious Target Tree · S&T
목표 설계

크고 담대한 목표를 꼭대기에 두고, 그것을 이루기 위해 반드시 갖춰야 할 조건들을 단계적으로 펼쳐나가는 도구예요.

어떻게 쓰나요?

  1. 야심찬 목표(T) — 이루고 싶은 가장 크고 담대한 것을 꼭대기에 적어요
  2. 필요 조건(NC) — 목표가 이루어지려면 반드시 있어야 하는 조건들을 찾아요
  3. 각 조건을 이루려면 다시 무엇이 필요한지 아래로 펼쳐요
  4. 나무 전체가 완성되면 어디서부터 시작할지 순서가 자연스럽게 보여요
공부하다 모르는 게 생겼나요?
